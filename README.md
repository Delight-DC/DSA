Project Description

This project implements a NUST Campus Service Centre Simulation using Java. The system demonstrates the implementation and application of data structures and algorithms, including queues, singly linked lists, stacks, arrays, searching, and sorting algorithms.

How to Run the Program

1. Clone or download this repository.
2. Open the project using a Java-supported IDE.
3. Compile the Java source files.
4. Run the main Java program.
5. Follow the options displayed in the Campus Service Centre menu.
